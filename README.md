# 🎮 Registro de Treinadores Pokémon

Projeto desenvolvido em JavaScript puro para registrar treinadores Pokémon utilizando a PokéAPI, LocalStorage e manipulação de DOM.

---

# 📌 Sobre o Projeto

O sistema permite que o usuário:

- Registre seu nome
- Escolha um Pokémon favorito
- Busque automaticamente a imagem do Pokémon pela PokéAPI
- Salve os registros no LocalStorage
- Visualize um histórico recente
- Limpe os dados salvos

O projeto foi desenvolvido com foco em:

- Manipulação de DOM
- Eventos
- Consumo de API com `fetch`
- Programação assíncrona (`async/await`)
- Uso de LocalStorage
- Organização de código em JavaScript

---

# 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript ES6+
- PokéAPI
